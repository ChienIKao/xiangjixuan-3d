# 〈項脊軒志〉互動式三維教學網頁・結果報告

## 交付檔案

- `dist/index.html`：可雙擊離線開啟的單一發布檔，內嵌全部程式與樣式。
- `index.html`：開發入口與繁體中文頁面設定。
- `src/main.js`：建立介面、場景、導演與音效，處理 WebGL 閱讀備援、網址、全螢幕及測試介面。
- `src/styles.css`：淡彩宣紙介面、楷書字幕、直橫排版、時間軸、抽屜、工具列與響應式配置。
- `src/core/renderer.js`：相機飛行、導覽觀察範圍、自由探索 OrbitControls、resize、分頁暫停及按需繪製。
- `src/core/quality.js`：自動／手動畫質、DPR、陰影與持續低於門檻的降級判斷。
- `src/core/tween.js`：插值、緩動與減少動態偏好。
- `src/story/state.js`：38 句完整累積狀態、短暫狀態重置、人物整包取代、探索時期狀態。
- `src/story/director.js`：句子切換、鏡頭、說明卡、延遲音效與導覽／探索模式。
- `src/world/layout.js`：院落座標及客人赴宴路徑。
- `src/world/palette.js`：共用 Lambert 材質、幾何合併、墨線、頂點色、實例合併及群組淡入淡出。
- `src/world/build/architecture.js`：地面、鋪石、軒、中閨、廚、廳、外圍房舍、庭牆、籬牆、小門、四窗、門扉、屋頂、桌椅、書架、書冊、象笏與井。
- `src/world/build/plants.js`：桂、竹、蘭、雜樹、枇杷、雜草與山景。
- `src/world/people.js`：人物外觀、八種姿勢、移動路徑、攜物、回憶人物與淡出。
- `src/world/animals.js`：狗吠、廳中雞與庭階小鳥。
- `src/world/effects/index.js`：shader 雨絲與火焰、漣漪、方位、尺寸、日照／反照、光圈、腳印、聲波與標籤。
- `src/world/sky.js`：七種天色、漸層天空、霧、單一投影主光、低角度東方月光、月亮與星點。
- `src/world/world.js`：建築過渡、屋頂剖視、牆面淡化、植物生長、衰敗、門扇延遲及各場景系統協調。
- `src/ui/app.js`：封面、原文、語譯、注釋、提問、時間軸、對話、地點標籤、說明卡、探索時期、快捷鍵、觸控與偏好儲存。
- `src/audio.js`：WebAudio 即時合成雨、風、鳥、蟲、狗、足音、火、叩門及關門聲。
- `scripts/check-content.mjs`：指定的內容檢查，以及完整狀態、探索狀態與副本隔離檢查。
- `scripts/browser-smoke.mjs`：不需額外套件的本機 Chrome 離線瀏覽器測試。
- `README.md`：給老師及協助者的操作、快捷鍵、內容欄位、開發、配置與部署說明。
- `qa/`：桌面、手機及閱讀備援截圖；`browser-results.json` 記錄瀏覽器驗證，`build-results.json` 記錄單檔、語法及內容保留檢查。此目錄不用部署。
- `package.json`：只新增 `check` script，依賴版本與套件清單保持不變；`vite.config.js`、`package-lock.json` 未修改。

- 從 `file://` 開啟發布檔，實際逐句走過 38 句；另驗證 b38 → b2 → b19 → b10 的任意跳轉。

## 效能措施

- 使用 `setAnimationLoop` 推進狀態，但只在相機、動畫、互動或狀態變化時呼叫 render；靜止時停止繪製，背景分頁暫停動畫與音效。
- 瓦、鋪石、書冊、竹、籬、草與腳印採實例化；靜態建築依材質合併，固定結構再以頂點色合併，墨線合併成少數 LineSegments。
- 靜態合併物件停用矩陣自動更新；人物路徑長度預先計算；標籤只在相機或目標變動時重新投影。
- 只有主光投影，使用 PCFShadowMap，陰影範圍約 ±16 公尺；陰影僅於需要時更新。細小動物、人物頭部與教學粒子不額外投影。
- 高／中／低 DPR 分別限制為 2／1.25／0.85，陰影 2048／1024／關閉；自動模式連續兩秒低於 40 FPS 才降級，不自動升級。
- 雨絲與火焰使用固定幾何和 shader，腳印為固定實例池；無後製、無 canvas CSS filter、無外部模型／字型／音檔，程式標籤貼圖最大 256 × 64。
- 本機 Chrome 在高畫質抽查九個場景：繪製呼叫 54～146 次，三角形 32,890～83,532 個。分家場景 b14 與足音場景 b26 均為 146 次；這是瀏覽器實測抽樣，不代表所有裝置的 FPS 保證。

## 已知限制與待實機確認

- 場景是依文本推想的低多邊形教學示意，人物動作、屋頂損壞、紙窗破洞、日照反射與歲月生長採簡化表現。
- 已以本機 Chrome 檢查桌面與模擬手機畫面；尚未在 Intel UHD 620、學校投影機、實體簡報筆、iPad 或手機上量測。30 FPS 的舊內顯目標需以該台設備確認。
- 合成音效已接上狀態與動畫，尚未用教室喇叭實際校聽音量與音色。
- 系統字型會隨電腦改變；標楷體缺少時會依楷書字型清單遞補。部分行動瀏覽器不提供全螢幕 API，介面會提示使用瀏覽器選單。
